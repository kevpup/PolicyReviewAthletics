# Policy Review Athletics

## Overview

This folder contains three primary documents and one folder of athletics policy documents. Together, these materials support an analysis of athlete biometric data references in NCAA Division I and sport-specific athletics policies using a contextual integrity framework.

## Folder Structure

```text
MAIN FOLDER/
├── References to Athlete Biometric Data.docx
├── Coded Data.xlsx
├── Master Document.xlsx
└── Policies/
```

## Contents

### 1. References to Athlete Biometric Data

The `References to Athlete Biometric Data.docx` document identifies references to athlete biometric data and related data constraints within the reviewed policy documents.

Each tab corresponds to a different sport. The `ALL` tab includes policies that apply across multiple sports, including the NCAA Division I Handbook.

Each paragraph represents a specific instance where athlete data may be mentioned. Paragraphs that remain unannotated were initially selected as potentially relevant but were later determined, based on consensus, to fall outside the scope of this research.

Annotated paragraphs are coded using the contextual integrity approach described by Shvartzshnaider et al. in *Going Against the (Appropriate) Flow: A Contextual Integrity Approach to Privacy Policy Analysis*. Different color codes correspond to different elements of contextual integrity.

The results of this analysis are reflected in the `Coded Data.xlsx` document.

### 2. Coded Data

The `Coded Data.xlsx` document contains the results of the contextual integrity analysis.

The `sport` column indicates whether each policy applies to NCAA Division I athletics as a whole or to a specific sport, including soccer, basketball, tennis, swimming, and track and field.

The `document` column maps to a corresponding document in the `Policies/` folder.

The following columns are coded using the contextual integrity approach described by Shvartzshnaider et al. in *Going Against the (Appropriate) Flow: A Contextual Integrity Approach to Privacy Policy Analysis*:

- `Subject`
- `Information Type`
- `Sender`
- `Receiver`
- `Transmission Principle`
- `Purpose`

The `Notes` column contains personal notes about interesting or relevant details. The `Who is this flow protecting?` column identifies, based on consensus, who the policy appears intended to protect.

### 3. Master Document

The `Master Document.xlsx` file is an organizational tool for storing all documents reviewed during the analysis.

During the document identification process, each relevant document was:

1. Identified
2. Saved as a PDF
3. Linked in the Master Document using the document link field
4. Logged with its page count
5. Marked with a status indicating whether it mentioned athlete data
6. Supplemented with notes where applicable

### 4. Policies Folder

The `Policies/` folder stores the raw PDF versions of all policy documents referenced in the Master Document. These PDFs serve as the source materials for the analysis.
